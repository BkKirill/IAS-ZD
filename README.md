# ИАС-Жд — мониторинг состояния железнодорожной инфраструктуры

Информационно-аналитическая система (веб-приложение) мониторинга состояния железнодорожной
инфраструктуры Самарской области на основе открытых данных. Проект учебной практики
(ПГУТИ, кафедра ИСТ, направление 09.03.02 «Информационные системы и технологии»).

Используются только российские сервисы:

| Источник | Что даёт |
|---|---|
| API Яндекс Погоды | температура, ветер, порывы, осадки в точке объекта |
| API Яндекс Расписаний | число поездов со станции за сутки, коды станций |
| JavaScript API Яндекс Карт | интерактивная карта |
| Сайты ОАО «РЖД», региональные СМИ | сведения о ремонтах (ручной ввод или CSV) |

## Что умеет

- раз в час автоматически собирает данные по 17 объектам Самарской области (станции, мосты,
  переезд, перегоны) и по кнопке «Обновить данные сейчас»;
- по правилам анализа присваивает объекту состояние: **норма**, **неблагоприятная погода**
  («сильный мороз», «жара», «сильный ветер», «сильные осадки»), **ремонт** / **ограничение скорости**,
  **движение закрыто**;
- показывает объекты на Яндекс Картах цветом по состоянию, по щелчку — карточка с погодой,
  числом поездов, ремонтами и причинами;
- хранит историю наблюдений, строит график, формирует отчёт за период с выгрузкой в CSV;
- ведёт журнал работы источников; ошибка одного источника не останавливает остальные.

## Страницы

| Адрес | Что там |
|---|---|
| `/` | карта и таблица объектов |
| `/history` | история наблюдений и график по объекту |
| `/restrictions` | ремонты и ограничения: список, форма ввода, импорт CSV |
| `/report` | отчёт за период, выгрузка в CSV |
| `/log` | журнал работы источников данных |

## Запуск

1. Установить Python 3 и зависимости:
   ```
   py -m pip install -r requirements.txt
   ```
2. Скопировать `.env.example` в `.env` и вписать свои ключи из
   [кабинета разработчика Яндекса](https://developer.tech.yandex.ru/):
   - `YANDEX_MAPS_KEY` — JavaScript API Яндекс Карт (в настройках ключа указать HTTP Referer `localhost`);
   - `YANDEX_WEATHER_KEY` — API Яндекс Погоды;
   - `YANDEX_RASP_KEY` — API Яндекс Расписаний.
3. Запустить `Запуск.bat` (или `py app.py`) и открыть http://localhost:5000

Без ключей данные не собираются. Для проверки без ключей можно включить тестовый режим
`DEMO_IF_NO_KEY=1` — тогда значения случайные и помечаются как тестовые.

## Архитектура

```
Источники (Яндекс Погода, Яндекс Расписания, ремонты РЖД)
        ↓
Модуль сбора данных (collectors/) + планировщик
        ↓
Модуль анализа (analysis.py): правила → состояние + причины
        ↓
База данных SQLite (db.py): objects, observations, restrictions, collector_log
        ↓
Веб-сервер Flask (app.py): страницы и JSON API
        ↓
Веб-интерфейс: Яндекс Карты, таблицы, график, отчёт
```

```
app.py              веб-сервер, страницы, JSON API, планировщик
config.py           настройки и ключи (читаются из .env)
db.py               база данных SQLite
analysis.py         правила анализа состояния
collectors/         сборщики данных (один файл — один источник)
data/               справочник объектов и ремонты (CSV)
templates/, static/ веб-интерфейс
docs/               пояснительная записка
```

Подробное описание — в [docs/Пояснительная_записка.md](docs/Пояснительная_записка.md).

## Как расширить

- **Новый источник данных:** файл в `collectors/` с классом-наследником `BaseCollector`
  и методом `collect(obj, day)`, затем добавить его в список `COLLECTORS` в `collectors/__init__.py`.
- **Новое правило анализа:** функция в `analysis.py`, затем добавить её в список `RULES`.
- **Новый регион:** дополнить `data/objects.csv`; коды станций система найдёт сама по координатам.

## Технологии

Python 3, Flask, SQLite, HTML/CSS/JavaScript, API Яндекс Карт 2.1, API Яндекс Погоды, API Яндекс Расписаний v3.
